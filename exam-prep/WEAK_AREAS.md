## Starter list of common weak spots (delete when irrelevant)

| Topic | Rule |
|---|---|
| Deployment name vs model name | SDKs call the deployment name |
| Control-plane vs data-plane roles | Calling a model needs a data-plane role |
| Structured output | Guarantees shape, not truth |
| Hybrid vs semantic ranker | Hybrid fuses keyword and vector; semantic re-ranks top results |
| Indirect prompt injection | Arrives through documents, images, audio, tool results |
| Free-tier limits | Search Free: 50 MB, 3 indexes, no private endpoints |
| Approval flows | Enforced by tool configuration or code, not prose |
| Evaluators | Offline scoring; filters are runtime protection |
